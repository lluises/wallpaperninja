# Wallpaper Ninja

Ubuntu-Touch app to manage wallpapers with options like random wallpapers, automatic day/night images, etc.

Website: [kitsune.cat](https://kitsune.cat)


## How to build

Use the [clickable](https://clickable-ut.dev) tool.

```bash
clickable build
```

then you can do:

```bash
clickable install
```
